Examples

A tutorial in 13 scripts. Each script is self-contained and documented in its docstring; together they show the features of physXAI 1.0 in a sensible reading order. All examples use the data of the BOPTEST case Bestest Hydronic Heat Pump (data/bestest_hydronic_heat_pump/pid_data.csv, 14 days, one sample every 15 min): the air temperature of the zone and the electrical power of the heat pump.

python examples/01_first_model.py

The scripts find the data relative to the repository and can be run from any directory. Results (configs, metrics, models and html reports) are written to results/<script>/.

Topic

Shows

Notes:

  • The data covers only 14 days. The split shortens its blocks to get enough of them and warns about it.

  • The examples train with the full number of epochs. The CI runs every example with one epoch per training (python tests/smoke_examples.py).
