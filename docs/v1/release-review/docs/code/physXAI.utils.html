physXAI.utils.seed module

Global random seed of physXAI.

set_seed seeds Python, NumPy and Keras (TensorFlow) once for a whole script and acts as the default random_state / random_seed of all physXAI objects. A seed passed to an object explicitly takes precedence. Without any seed, a fresh one is drawn and stored in the configs, so every run can be reproduced afterwards.

On a CPU, a seeded run is reproduced exactly. On a GPU, some TensorFlow kernels are not deterministic (e.g. reductions with atomic additions), so two runs with the same seed differ slightly, unless set_seed(seed, deterministic=True) enables the deterministic kernels of TensorFlow.

physXAI.utils.seed.set_seed(seed, deterministic=False)[source]

Sets the global seed of physXAI.

Parameters:

  • seed (int | None) – The seed. None clears the global seed, so objects draw fresh seeds again.

  • deterministic (bool) – Also enables the deterministic operations of TensorFlow (tf.config.experimental.enable_op_determinism), so runs on a GPU are reproduced exactly as well. It slows down the training on a GPU, operations without a deterministic implementation raise an error, and it stays enabled for the rest of the process (TensorFlow cannot disable it again). On a CPU it is not needed.

Return type:

None
