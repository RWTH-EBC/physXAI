1""" 

2Modular artificial neural networks: a trainable model built from a `physXAI.expr` graph. 

3 

4 >>> from physXAI import expr as px 

5 >>> v = px.Vars() 

6 >>> model = ModularANN(px.Linear([v.mDot, v.load, v.mDot * (v.T_in - v.T), v.T]), solver="ols") 

7 

8Physical arithmetic (like the heat flow above) is part of the keras model. It is therefore 

9recomputed in every step of a recursive prediction and exported to AgentLib-MPC together with 

10the model, so the MPC only needs the raw inputs. 

11"""
