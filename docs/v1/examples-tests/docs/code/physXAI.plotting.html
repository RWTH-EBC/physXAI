physXAI.plotting.plotting module

Plots of training data, predictions and errors (plotly).

model_report(td, title) combines all plots of a trained model into one figure. Figures are not shown by default (show=False); the model pipelines save them as html file next to the model instead.

Stacks figures into one figure with one row per figure.
