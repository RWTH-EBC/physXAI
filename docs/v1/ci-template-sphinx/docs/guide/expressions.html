Expressions: physics inside the model

physXAI.expr is one language for physically motivated terms and trainable blocks. An expression can be evaluated on data (NumPy / pandas), built into a Keras model and translated to CasADi for the MPC.

from physXAI import expr as px

v = px.Vars()                       # v.T, v.T_in, v['Func(logistic)']: no declarations needed
vT = v.mDot * (v.T_in - v.T)        # heat flow of the supply air

Inside the model (recommended)

Derived quantities are best placed inside the model. They are recomputed in every step of a recursive prediction, and the MPC only needs the raw inputs:

from physXAI.models import ModularANN

model = ModularANN(px.Linear([v.mDot, v.load, vT, v.T]), solver="ols")   # linear regression in closed form
prep = PreprocessingSingleStep(output=px.Change("T"))
td = prep.pipeline(path, model=model)    # the inputs are taken from the model
model.pipeline(td)

prep.pipeline(path, model=model) collects the free variables of the model (including lags like v.T.lag(1)) and orders them as AgentLib-MPC expects: the recursive feature and its lags last.

As data column (fallback)

If a quantity has to be a column of the data, e.g. the target of a PINN, it is added with columns:

prep = PreprocessingSingleStep(inputs=["mDot", "vT", "T"], output="Change(T)", columns={"vT": vT})

The MPC then has to provide vT as input. In a recursive evaluation, columns depending on the predicted feature are recomputed in every step.

Arithmetic (+ - * / **), px.exp, px.relu, px.sigmoid, px.softplus, px.tanh and constants (px.Const) combine them. Blocks normalize their inputs; arithmetic works on physical values.

v = px.Vars()
T, T_amb, u_hp = v.reaTZon_y, v.weaSta_reaWeaTDryBul_y, v.oveHeaPumY_u
architecture = px.Linear([
    T - T_amb,                                # losses through the envelope
    u_hp, u_hp.lag(1),                        # heat pump with delay
    v.weaSta_reaWeaHDirNor_y,                 # solar gains
    px.MLP([u_hp, T_amb, T], n_neurons=8),    # residual dynamics
], normalize=True)
model = ModularANN(architecture, epochs=200)

The whole graph is stored in the model config (model.get_config()), shared nodes stay shared. ConstrainedRegression(inputs, monotonies, convexities) fits a linear regression on expressions with monotonicity and convexity constraints (CasADi / IPOPT).
