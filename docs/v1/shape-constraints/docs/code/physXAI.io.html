physXAI.io package

Input / output of physXAI runs: run directories and the export for AgentLib-MPC.

Submodules

physXAI.io.agentlib module

Export of physXAI models for AgentLib-MPC.

AgentLib-MPC (agentlib_mpc.machine_learning_plugins.physXAI) executes a physXAI training script and reads the following files from the run directory:

  • {name}_preprocessing.json (inputs, output, shift, time_step, split info)

  • {name}_model.json (at least __class_name__)

  • {name}_training_data.json (optional, stored as training info)

  • {name}.keras or {name}.joblib (the trained model)

The input and output names follow two conventions, which AgentLib-MPC parses: Change(X) denotes an output predicting the difference of X, and X_lagN the value of X N time steps in the past. check_agentlib_compatibility validates the same rules as AgentLib-MPC before a model is trained, so a run fails early instead of after training.

physXAI.io.run module

Output directory of a training run.

A Run replaces the global Logger of physXAI < 1.0. It is an explicit object holding the directory all files of a run are written to. Paths are absolute or relative to the current working directory; they are never resolved relative to a git repository, so physXAI behaves the same when installed as a package. Nothing is ever deleted and no interactive prompts are shown, which makes runs safe for parameter sweeps and CI.

save(name, preprocessing=None, model=None, training_data=None, trained_model=None, plot=True)[source]

Saves a trained model with everything needed to reproduce, compare and use it.

Files (all optional, depending on the arguments):

  • {name}_preprocessing.json: config of the preprocessing (PreprocessingData.from_config).

  • {name}_model.json: config of the model (AbstractModel.model_from_config).

  • {name}_training_data.json: metrics, horizon metrics, training time and history.

  • {name}.keras or {name}.joblib: the trained model.

  • {name}.html: the model report (plot=True).

The files follow the layout AgentLib-MPC reads (see save_for_agentlib), and physXAI.evaluation.comparison.ModelComparison compares saved runs.

Parameters:

  • name (str) – Name of the model, the prefix of all files.

  • preprocessing – The preprocessing object.

  • model – The physXAI model object.

  • training_data – The evaluated training data.

  • trained_model – The trained model. Defaults to model.trained_model, set by model.pipeline.

  • plot (bool) – Whether to save the model report (needs the model and the evaluated training data).

Returns:

The written files by kind (‘preprocessing’, ‘model_config’, ‘training_data’, ‘model’, ‘plot’).

Return type:

dict
