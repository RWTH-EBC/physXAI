physXAI.agentlib_mpc_plugin.example module

Training script of the AgentLib-MPC example ‘one_room_mpc’: a classical ANN of the room temperature (1000 epochs).

example.py is used by the example, example_ci.py (the same with 10 epochs) by the CI of AgentLib-MPC. A tutorial on the export is examples/13_agentlib_mpc.py.
