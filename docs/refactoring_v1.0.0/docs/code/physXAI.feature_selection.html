physXAI.feature_selection.selection module

Feature selection by backward elimination (experimental).

A small single step error does not imply a good MPC performance. The selection therefore uses the error of the recursive prediction over a horizon (criterion='horizon', requires PreprocessingSingleStep(eval_horizon=...)) and repeats every evaluation on several block splits (n_repeats), so the spread of the criterion can be compared to the differences between candidates. Optionally, the sign of the sensitivity of the prediction to the control inputs is checked (controls): a model whose prediction reacts to a control with the wrong sign is of little use in an MPC, even if its error is small.

The criterion is computed on the validation data, which also stops the training early. The score of the selected inputs is therefore optimistic: evaluate the final model on the test data (td.metrics, td.horizon_metrics).

>>> fs = FeatureSelection(prep, LinearRegressionModel(), controls={'oveHeaPumY_u': 1}, n_repeats=3)
>>> result = fs.run(file_path)
>>> result.selected.inputs

class physXAI.feature_selection.selection.FeatureSelection(preprocessing, model, criterion=None, mpc_horizon=None, first_step_weight=None, bias_weight=0.0, n_repeats=1, fixed_inputs=None, ascending_lag_order=True, controls=None, min_sign_share=0.95, tolerance=0.0)[source]

Bases: object

Backward elimination of inputs.

Starting from all inputs of the preprocessing, every step removes the input whose removal gives the best criterion. The preprocessing passed in is not changed.

Parameters:

  • preprocessing (PreprocessingData) – Preprocessing holding all candidate inputs (PreprocessingSingleStep).

  • model – The physXAI model, trained for every candidate (without plots and saving).

  • criterion (str | None) – ‘horizon’ (default if the preprocessing has an eval_horizon): step weighted RMSE of the recursive prediction on the validation data, plus bias_weight times its absolute bias at mpc_horizon. ‘single_step’: single step RMSE on the validation data.

  • mpc_horizon (int | str | None) – Step (or time delta string) of the horizon at which the bias is evaluated. Defaults to the evaluation horizon.

  • first_step_weight (float | None) – Optional share of the first step in the horizon RMSE (None: all steps alike).

  • bias_weight (float) – Weight of the absolute bias in the criterion.

  • n_repeats (int) – Number of block splits (seeds) every candidate is evaluated on.

  • fixed_inputs (list[str] | None) – Inputs which are never removed. Controls and the recursive feature are always kept.

  • ascending_lag_order (bool) – Remove the highest lag of a feature first and the feature itself last.

  • controls (dict[str, int] | None) – {control input: expected sign (+1 / -1)} of the sensitivity of the prediction.

  • min_sign_share (float) – Share of validation samples that needs the expected sign for a plausible model.

  • tolerance (float) – Relative tolerance: the smallest set of inputs with a criterion within (1 + tolerance) * best criterion is selected.
