physXAI.models.ann.pinn.physics module

Loss and metrics of physics-informed training.

The loss of a model with one output y and physics targets p_1, …, p_n (e.g. the prediction of a physical model of the same quantity) is

L = mse(y_hat, y) / s + sum_i w_i * mse(y_hat, p_i) / s

with the characteristic scale s = var(y_train) (normalize_terms=True, else s = 1). The scale makes the terms dimensionless: the data term is 1 - R^2 on the training data and w_i is the relative importance of physics target i. The terms are not averaged, so adding a physics term does not change the weight of the data term. The weights encode the trust in the physics and are chosen by validation (e.g. the error over the prediction horizon); they are not adapted during the training.

The targets passed to keras are [y, p_1, ..., p_n] (columns), the model predicts y only, so the trained model can be used (and exported to AgentLib-MPC) like any other single output model.

class physXAI.models.ann.pinn.physics.PhysicsResidual(residual, weight=1.0, name='physics', scale=None)[source]

Bases: object

A physics residual r(x, y; theta) to be close to zero, e.g. the disagreement of the prediction with a grey-box model with trainable physical parameters theta (px.Param, px.positive):

dT = (1 - px.exp(-dt / tau)) * (v.T_amb - v.T + K_u * v.u_hp) # exact zero order hold residual = PhysicsResidual(px.Prediction() - dT, weight=1.0)

px.Prediction() is the output of the model. All other variables are data columns at the time of the inputs, px.Target(name) at the predicted time; they become loss columns of the preprocessing and do not have to be inputs of the model. Only the network is saved and exported, the residual is used in the training only.

Parameters:

  • residual – The residual expression. It has to contain px.Prediction(); parameters (px.Param) are the only trainable parts (no blocks), so they keep their physical meaning.

  • weight (float) – Weight of the residual in the loss (relative to the data term).

  • name (str) – Name of the term, in lower case (history: ‘<name>_loss’, ‘<name>_fit_loss’).

  • scale (float | None) – Characteristic squared magnitude of the residual (the loss term is mean(r^2) / scale). Defaults to the variance of the training targets, i.e. a residual in output units.

physXAI.models.ann.pinn.physics.fit_with_physics(model, td, settings, physics, mode='calibrate', physics_learning_rate=None)[source]

Trains a single output keras model on the data and a physics residual.

The residual is evaluated twice with shared parameters theta: with the prediction (r_hat, the physics term of the network) and with the measured target (r_y, the fit of the physics model to the data).

  • ‘calibrate’ (default): 1. theta is fitted to the data on mean(r_y^2) (grey-box identification, deterministic by least squares, see calibrate_least_squares; gradient descent if the residual has no CasADi form), 2. theta is frozen and the network is trained on the data and w * mean(r_hat^2). The parameters cannot drift to follow the network.

  • ‘joint’: network and theta together on data + w * r_hat + r_y.

  • ‘fixed’: theta stays at its initial values, the network is trained on data + w * r_hat.

Parameters:

  • model – The keras model (one output). It is trained in place.

  • td – Single step training data holding the loss columns of the residual.

  • settings – The physXAI model (epochs, batch_size, learning_rate, early_stopping_epochs, random_seed).

  • physics (PhysicsResidual) – The residual.

  • mode (str) – ‘calibrate’, ‘joint’ or ‘fixed’.

  • physics_learning_rate (float | None) – Learning rate of a calibration by gradient descent. Defaults to 10 x the learning rate.

Returns:

‘name’ (of the residual), ‘parameters’ (trained values by name), ‘fit’ (RMSE of the physics term and of the physics model

per split), ‘calibration_record’ (result of the least squares solver or the history of the gradient descent, None without calibration) and ‘record’ (keras history of the training of the network).

Return type:

dict
