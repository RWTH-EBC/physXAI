physXAI.models.modular.modular_ann module

Modular artificial neural networks: a trainable model built from a physXAI.expr graph.

>>> from physXAI import expr as px
>>> v = px.Vars()
>>> model = ModularANN(px.Linear([v.mDot, v.load, v.mDot * (v.T_in - v.T), v.T]), solver="ols")

Physical arithmetic (like the heat flow above) is part of the keras model. It is therefore recomputed in every step of a recursive prediction and exported to AgentLib-MPC together with the model, so the MPC only needs the raw inputs.

physXAI.models.modular.shape_constraints module

Shape constrained least squares: a linear regression on data only expressions whose prediction is monotonic or convex in raw data columns, guaranteed on a domain.

The model is y = b + sum_i w_i * phi_i(x) with terms phi_i (expressions of the raw columns x). Its derivative dy/dx_j = sum_i w_i * dphi_i/dx_j(x) is linear in the weights, so the constraint

s * d^k y / dx_j^k (x) >= 0 for all x in D (k = 1 monotonicity, k = 2 convexity, s = +-1)

is a family of linear constraints, one per point of the domain D (a semi-infinite program). It is solved with the exchange method: a quadratic program (the least squares problem) on a finite set of constraint points, the most violated points of D are searched and added, until no violation is left.

  • Domain ‘box’: the box of the training data (or bounds, e.g. the bounds of the MPC). If the derivative is multilinear in the columns it depends on (linear, bilinear and quadratic terms), its minimum over the box lies in a corner. All corners are constraint points, so the constraint holds on the whole box (‘exact’). Otherwise the box is searched with a Sobol sample and local minimizations from its worst points (‘verified’).

  • Domain ‘data’: the constraints hold on the training samples (‘data’).

Weights of single terms can additionally be bounded in sign (px.Linear(monotonicities=...)), which holds globally.
