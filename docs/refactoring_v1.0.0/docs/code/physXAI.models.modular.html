physXAI.models.modular.modular_ann module

Modular artificial neural networks: a trainable model built from a physXAI.expr graph.

>>> from physXAI import expr as px
>>> v = px.Vars()
>>> model = ModularANN(px.Linear([v.mDot, v.load, v.mDot * (v.T_in - v.T), v.T]), solver="ols")

Physical arithmetic (like the heat flow above) is part of the keras model. It is therefore recomputed in every step of a recursive prediction and exported to AgentLib-MPC together with the model, so the MPC only needs the raw inputs.

class physXAI.models.modular.modular_ann.ModularANN(architecture, rescale_output=False, solver='adam', batch_size=32, epochs=1000, learning_rate=0.001, early_stopping_epochs=100, random_seed=None, **kwargs)[source]

Bases: ANNModel

Trainable keras model defined by an expression graph.

Parameters:

  • architecture (Expr | dict) – The expression computing the output, e.g. px.Linear([...]).

  • rescale_output (bool) – Rescale the output with mean and standard deviation of the training targets.

  • solver (str) – ‘adam’ (gradient descent) or ‘ols’ (closed form least squares; the architecture has to be a Linear block on data only inputs without monotonicities).

  • batch_size (int) – Batch size of the training.

  • epochs (int) – Maximum number of epochs.

  • learning_rate (float) – Learning rate of the Adam optimizer.

  • early_stopping_epochs (int | None) – Patience of the early stopping on the validation loss (None: no early stopping).

  • random_seed (int | None) – Seed of the weights and the batch order, set when the model is generated. Defaults to the global seed (physXAI.set_seed), else a new seed is drawn (stored in the config).
