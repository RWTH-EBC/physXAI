class physXAI.models.ann.ann_design.RNNModel(rnn_units=32, rnn_layer='RNN', epochs=1000, learning_rate=0.001, batch_size=32, early_stopping_epochs=100, random_seed=42, feature_architecture=None, loss_on='trajectory', first_step_weight=None, step_weights=None, **kwargs)[source]

Bases: MultiStepModel

Recurrent neural network (SimpleRNN, GRU or LSTM) for multi step predictions.

The model warms itself up: starting from zero states, it is applied to the warmup_width measured steps in front of the prediction, which are not part of the loss. AgentLib-MPC warms the model up the same way, so there is no separate initialization model.

Predicting the change of a feature (output px.Change('T')) is recommended. The trajectory of T is then the measured start value plus the accumulated changes, and the loss is computed on that trajectory (loss_on='trajectory'). If T is also an input of the model, the predicted T is fed back during the prediction (closed loop), as in an MPC.

The saved model (save_model, save_for_agentlib) is the step model [sequence, *states] -> [prediction, *states], which AgentLib-MPC evaluates one step at a time.

Parameters:

  • rnn_units (int) – Number of units of the recurrent layer.

  • rnn_layer (str) – Type of the recurrent layer (‘RNN’, ‘GRU’ or ‘LSTM’).

  • epochs (int) – Number of training epochs.

  • learning_rate (float) – Learning rate of the Adam optimizer.

  • batch_size (int) – Number of sequences per batch.

  • early_stopping_epochs (int | None) – Patience of the early stopping on the validation loss (None disables it).

  • random_seed (int) – Seed of the weight initialization, set when the model is generated.

  • feature_architecture (Expr | list[physXAI.expr.core.Expr] | dict | None) – An expression (physXAI.expr), or a list of them, building the inputs of the recurrent layer out of the input features. Variables are not normalized, wrap them in px.Normalize where needed.

  • loss_on (str) – ‘trajectory’ (default): loss on the trajectory of the predicted features, i.e. on the accumulated changes. ‘outputs’: loss on the outputs (e.g. the changes) themselves.

  • first_step_weight (float | None) – Optional share of the first predicted step in the loss, the other steps share the rest. None weights all steps equally.

  • step_weights (list[float] | None) – Optional weight per predicted step (overrides first_step_weight).
