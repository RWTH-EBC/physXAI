Constructs a hybrid Keras model that combines a pre-trained linear regression model with a Radial Basis Function (RBF) network. The RBF network is trained to model the residuals (errors) of the linear regression model.

The final prediction is the sum of the linear model’s prediction and the RBF network’s prediction (which learns the residuals).

physXAI.models.ann.model_construction.rnn_models module

Construction of recurrent (multi step) models.

Two keras models are built:

  • The step model rnn_step maps [sequence, *states] -> [prediction, *states] for a sequence of any length. It is the model that is saved and used in AgentLib-MPC, which applies it one step at a time and warms its states up on the measured past.

  • The sequence model wraps the step model for training and evaluation. It starts from zero states, warms up on the first warmup steps of a sequence (not part of the loss) and predicts the following horizon steps:

    • An output ‘Change(T)’ is accumulated to the trajectory of T, starting from the measured value T(t0), so the model can be trained on the trajectory.

    • If a predicted feature is also an input of the model, it is fed back during the prediction (closed loop), as in an MPC. During the warmup the measured values are used.

physXAI.models.ann.model_construction.rnn_models.build_pcnn_step_model(config, td, terms, name='rnn_step')[source]

Builds the step model of a physically consistent neural network (PCNN, Di Natale et al. 2022, Applied Energy 325, 119806), [sequence, E, *states of f] -> [change of T, E, *states of f].

The predicted feature T (input and output Change(T)) is the sum of the unforced dynamics D and the energy accumulator E:

E(k+1) = E(k) + sum_heating a * u(k) - sum_cooling d * u(k) + sum_losses b * (T_x(k) - T(k)) D(k+1) = D(k) + f(D(k), x(k)), D(k) = T(k) - E(k)

f is a recurrent network on D and the remaining inputs x, which excludes the controls and the temperatures of the losses. With a, b, d > 0 and 1 - sum b > 0, T increases with heating, decreases with cooling and increases with the temperatures T_x over the whole horizon, for any f. The parameters work in physical units, f on normalized values.

Only keras layers translated by AgentLib-MPC are used (input slices, constants, subtract, multiply, concatenate, dense, simple_rnn, normalization, rescaling, add), the layer names carry their types.

Parameters:

  • config (dict) – Settings, validated by RNNModelConstruction_config (rnn_units, rnn_layer of f).

  • td – TrainingDataMultiStep with one output Change(T) and T as input.

  • terms (list[physXAI.models.ann.model_construction.rnn_models.PCNNTerm]) – The terms of the energy accumulator.

  • name (str) – Name of the model.

Return type:

Model
